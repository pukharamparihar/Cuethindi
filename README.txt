# CUET PG Hindi Website

## Upload
Upload `index.html`, `style.css`, and `script.js` to GitHub Pages, Netlify, Vercel, or any normal web hosting.

## Important
The website is a front-end template. Replace the toast placeholders with your actual PDF links and mock-test pages.

Suggested folders:
- assets/
- notes/
- pyq/
- mocks/

Then change buttons in `index.html` to links such as:
`href="notes/bhaktikal.pdf"`
`href="mocks/mock1.html"`
